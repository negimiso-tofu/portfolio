# portfolio

**HTML / CSS / JavaScript だけで作った自主制作サイト置き場。** フレームワーク・CMS・ビルドツール・外部ライブラリは使っていない。

公開: https://leeks8542-dotcom.github.io/portfolio/

## 中身は index.html と、作品ごとのディレクトリだけ

ルートの `index.html` が作品一覧。各作品は独立していて、そのディレクトリだけコピーしても動く。依存関係なし、`npm install` なし。ブラウザで開けば終わり。

## 作品

| ディレクトリ | 何を作ったか | 実装したこと |
|---|---|---|
| `sushi-hp/` | 架空の鮨店のコーポレートサイト | レスポンシブ、ハンバーガーメニュー、スクロール連動の表示アニメーション、縦書きコピー、`aria-label` |
| `icarus-hp/` | イカロス神話をスクロールで追う読み物 | スクロール位置に応じた状態管理、高度計とHUDの連動、演出のオン/オフ切替、スキップリンク |

`icarus-hp` は「一度上がった高度には戻れない」という物語の構造を、UIの挙動そのもので表現している。読み進めると高度が上がり、戻ろうとすると損傷した翼が抵抗する。

店名・住所・電話番号・団体名はすべて架空。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 作品一覧。スタイルは同ファイル内に直書き |
| `<作品>/index.html` | 各作品の本体 |
| `<作品>/styles.css` | 各作品のスタイル |
| `<作品>/script.js` | 各作品の挙動 |
| `<作品>/*.png`, `assets/` | 画像 |

## ローカルで開く

```bash
git clone https://github.com/leeks8542-dotcom/portfolio.git
cd portfolio
```

`index.html` をブラウザで開く。サーバーは不要。

パスの都合で表示が崩れる場合だけ、簡易サーバーを立てる。

```bash
python -m http.server 8000
```

## 決めていること

- フレームワークを使わない。何が動いているか全部読める状態を保つ
- 外部CDNに依存しない。オフラインでも開く（Webフォントを除く）
- レスポンシブ対応（768px / 1024px）
- 実在の店舗・企業を装わない
- `prefers-reduced-motion` を尊重する

## 未対応

- 画像が重い。`sushi-hp` のヒーロー画像は約1.7MB。WebP化と圧縮は未実施
- フォームは見た目のみ。送信処理は実装していない
