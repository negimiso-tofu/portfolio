## 収録作品

### 銀座 鮨しずく（架空の飲食店サイト）

[作品を見る](./sushi-hp/) ／ [ソース](./sushi-hp)

高級鮨店のコーポレートサイト。落ち着いた黒と金を基調に、縦書きのコピーで和の余白を表現しました。

- **狙った案件種別**：飲食・店舗向けコーポレートサイト
- **使用技術**：HTML / CSS / JavaScript（フレームワーク不使用）
- **実装ポイント**：レスポンシブ対応、ハンバーガーメニュー、スクロール連動の表示アニメーション、`aria-label` による支援技術対応

### IKAROS — 太陽へ至る航跡（インタラクティブ資料）

[作品を見る](./icarus-hp/) ／ [ソース](./icarus-hp)

イカロス神話をスクロールでたどる読み物。高度計とHUDが読み進めに連動し、「一度上がった高度には戻れない」という物語の構造を、UIそのもので表現しています。

- **狙った案件種別**：キャンペーンLP、体験型コンテンツ
- **使用技術**：HTML / CSS / JavaScript（フレームワーク不使用）
- **実装ポイント**：スクロール位置に応じた状態管理、演出のオン/オフ切替（`prefers-reduced-motion` 配慮）、スキップリンク
