## 構成（4ページ）

```
reform-hp/
├─ index.html      トップ（会社概要を #company セクションとして内包）
├─ works.html      施工事例（絞り込み付き・6件）
├─ service.html    サービス・料金（#mizumawari #gaiheki #taishin #barrierfree #price #hojokin #mitsumori #faq）
├─ contact.html    お問い合わせ（現地調査の依頼フォーム）
├─ styles.css      骨子用。Codexが全面的に書き換えてよい
├─ script.js       ナビ開閉 ＋ 施工事例の絞り込み
├─ sitemap.xml
└─ assets/favicon.svg（仮）
```

会社概要を独立ページにせず、トップの `#company` に置いています。4ページに収めつつ、
建設業許可番号・加入保険といった信用に直結する情報を落とさないための判断です。

## 施工事例の絞り込み（この作品の技術的な見せ場）

`works.html` ＋ `script.js`。**カテゴリ × 予算帯**の2軸。

設計の意図は `script.js` の冒頭コメントに書いてあります。要点は4つ。

1. **HTMLに全件を書き出しておく。** JSが動かない環境でも全部読める
2. **状態は `aria-pressed` に持たせる。** 見た目と支援技術で食い違わせない
3. **件数を `aria-live="polite"` で読み上げる。** 画面を見ていない人にも結果が伝わる
4. **URLのクエリに状態を残す。** 絞り込んだ一覧をそのまま人に送れる（`?cat=zenmen` など）

動作確認済み（2026-09-13）：全6件 → 水まわり1件 → 水まわり×150万以上で0件＋該当なし表示 → リセットで6件。
`?cat=zenmen` で開くと2件に絞られた状態で開く。コンソールエラーなし。

## Codexへの引き継ぎ事項

1. `styles.css` 冒頭の**残すべき3点**は消さないこと
2. **絞り込みの `aria-pressed` / `hidden` / `aria-live` の対応関係を壊さないこと。** 見た目だけ変えてください
3. `.img-placeholder` の `aria-label` の文言を、そのまま `alt` に移す
4. 施工写真は**ビフォー・アフターの並べ方**を設計してください。この業種でいちばん見られる部分です
5. 電話番号はスマホで最も目立つ位置に。雨漏りの相談は電話で来ます
6. ヘッダーとフッターは4ページで同じHTML。1つ直したら4つとも
